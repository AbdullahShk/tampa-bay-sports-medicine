# Tampa Bay Sports Medicine Society - Homepage Redesign Concept

An original static homepage redesign concept prepared for a website redesign proposal. This is an independent preview. Current Society information is at https://tampabaysportsmed.org/.

- Original illustrative AI-generated imagery depicts fictional people and settings, not actual Society members, events, or endorsements.
- Membership, sponsorship, education, and general contact forms preview the proposed inquiry experience. They do not send or save details.
- Pages preserve noindex,nofollow to avoid appearing in search as the Society's live website.

## GitHub Pages and editing

Select **Deploy from a branch**, branch **main**, and folder **/ (root)**. There is no build step or paid dependency.

Edit index.html for the homepage, the three *-contact.html files for focused inquiries, and contact.html for general questions. styles.css includes the original design rules and four embedded font files; readability.css separately controls readable typography, caption, navigation, and responsive layouts. app.js includes the interactions and three original illustrative photos in a data-URI registry, each stored once. Static photo elements use tiny inline SVG placeholders until the registry initializes, avoiding requests for missing photo files. The original vector brand mark is assets/brand-mark.svg.
