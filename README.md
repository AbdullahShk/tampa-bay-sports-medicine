# Tampa Bay Sports Medicine Society - Homepage Redesign Concept

An original static homepage redesign concept prepared for a website redesign proposal. This is an independent design preview; the Society's current information is available at https://tampabaysportsmed.org/.

## Preview content

- Original illustrative AI-generated images depict fictional people and settings, not real Society members, events, or endorsements.
- Membership, sponsorship, and education forms demonstrate the proposed inquiry experience. They do not send or save details.
- The preview preserves `noindex,nofollow` so it is not presented in search as the Society's live website.

## Hosting and editing

This site uses plain HTML, CSS, and JavaScript with local assets and no build step. For GitHub Pages, select **Deploy from a branch**, branch **main**, and folder **/ (root)**. The `.nojekyll` file disables Jekyll processing.

Edit `index.html` for the homepage and the three `*-contact.html` files for inquiry pages. Styles are in `styles.css` and `v2.css`; interactions are in `app.js`.
